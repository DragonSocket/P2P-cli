# Статус новой реализации

Выполнено: MVC-границы, внедрение портов, Linux TAP, MAC switching,
приватная Kademlia DHT, TTL/репликация имён, членство/heartbeat,
CLI + монитор + IPC, systemd unit, логирование/ротация, unit/network/process tests.

Остаётся для следующего этапа:
- Проверка двух Linux TAP на реальных хостах и игр через разные сети.
- STUN на том же сокете, NAT hole punching и fallback relay; тестовая NAT-матрица.
- Индивидуальные ключи пиров и подписанное владение именами.
- Системный DNS/NSS при необходимости прозрачного обращения по имени.
- Обособление прав TAP от непривилегированного сетевого процесса.
- Нагрузочные/длительные тесты, аудит протокола, метрики доставки.

Каталоги plan/ и tasks/ относятся к историческому плану attempt2.

## Objective

## Phase 0: Environment & Package Readiness
All commands must be executed from the project root.
1.  **Add Dependencies:** Run `uv add pytest pytest-asyncio pytest-mock --dev` to the root.
2.  **Workspace Lifecycle:** 
    - Check the root `pyproject.toml`. If `p2pvpn_common` is not in the `[tool.uv.workspace].members` array, update the array to include `'packages/p2pvpn_common'`.
    - Register the package: `uv add --editable ./packages/p2pvpn_common`.
    - **Verify Registration:** Run `uv run python -c "import p2pvpn_common; print('Package found')"` to ensure the workspace is correctly configured.
3.  **Namespace Scaffolding (The "Active Stub" Strategy):**
    Create the following directories and files with the provided stub implementations. The stubs return incorrect data to ensure test assertions fail during the "RED" phase.
    - `mkdir -p tests/p2pvpn_common/protocol/`
    - `mkdir -p packages/p2pvpn_common/p2pvpn_common/protocol/stun/`
    - `packages/p2pvpn_common/p2pvpn_common/__init__.py` (Empty)
    - `packages/p2pvpn_common/p2pvpn_common/protocol/__init__.py` (Empty)
    - `packages/p2pvpn_common/p2pvpn_common/protocol/stun/__init__.py` (Empty)
    - `packages/p2pvpn_common/p2pvpn_common/protocol/stun/client.py`:
      ```python
      class StunClient:
          def __init__(self, host: str, port: int):
              self.host = host
              self.port = port
          async def get_external_ip(self) -> tuple[str, int]:
              # Call the internal method to allow the mock to be intercepted
              await self._send_request(b"")
              return ("0.0.0.0", 0) # Dummy return to facilitate AssertionError
          async def _send_request(self, data: bytes) -> bytes:
              raise NotImplementedError()
      ```
    - `packages/p2pvpn_common/p2pvpn_common/protocol/stun/packet.py`:
      ```python
      class StunPacket:
          def __init__(self, message_type: int, transaction_id: bytes):
              self.message_type = message_type
              self.transaction_id = transaction_id

          @classmethod
          def parse(cls, data: bytes) -> "StunPacket":
              # Return incorrect data to force a controlled AssertionError
              return StunPacket(0x9999, b'WRONG_ID_12')
      ```

## Phase 1: Test Implementation
Create `tests/p2pvpn_common/protocol/test_stun.py`.

### Target API Contract
- `StunClient(host, port)` -> `await get_external_ip() -> (str, int)`
- `StunPacket.parse(data)` -> `StunPacket(message_type: int, transaction_id: bytes)`

### Test Scenarios
1.  **`test_stun_client_get_external_ip_logic`**
    - **Requirement:** Use `@pytest.mark.asyncio`.
    - **Requirement:** Use `mocker.patch` with `new_callable=unittest.mock.AsyncMock` targeting the string `"p2pvpn_common.protocol.stun.client.StunClient._send_request"`.
    - **Requirement:** Use absolute imports: `from p2pvpn_common.protocol.stun.client import StunClient`.
    - **Logic:**
        - Instantiate `StunClient(host="127.0.0.1", port=3478)`.
        - Mock `_send_request` to return: `STUN_RESPONSE_BYTES`.
        - **Assertion:** `assert result == ("93.184.216.34", 443)`.
    - **Test Vector (Binding Success Response Header - 20 bytes):** 
      `STUN_RESPONSE_BYTES = b'\x01\x01\x00\x00\x21\x12\xA4\x42\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00'`
2.  **`test_stun_packet_parsing_header`**
    - **Requirement:** Use absolute imports: `from p2pvpn_common.protocol.stun.packet import StunPacket`.
    - **Logic:**
        - `STUN_BINDING_REQUEST = b'\x00\x01\x00\x00\x21\x12\xA4\x42\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00'`
        - `result = StunPacket.parse(STUN_BINDING_REQUEST)`
        - **Assertions:** `assert result.message_type == 0x0001`, `assert result.transaction_id == b'\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00'` (12 bytes of zeros).

## Constraints
- **NO RUST.**
- **Python only.**
- **Use `pytest` and `pytest-asyncio`.**
- **Imports MUST be at the module level.**

## Success Criteria
1.  The stubbed package structure is correctly created and recognized by `uv`.
2.  `uv run pytest tests/p2pvpn_common/protocol/test_stun.py` is executed.
3.  **The tests fail with `AssertionError`**, confirming that the API contract is being exercised (via the mock) but the logic/stub does not match the expected contract.

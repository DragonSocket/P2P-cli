# Task 1.2: Extract Protocol Logic

## Description
Move the Ethernet/VPN protocol logic from `vpn_node.py` to `p2pvpn_common/protocol/packet.py`. This includes `MAGIC`, `TYPE_DATA`, `TYPE_HELLO`, `encode_data`, `encode_hello`, and `decode`.

## Requirements
- **Migration**: Move protocol constants and functions to `p2pvpn_common/protocol/packet.py`.
- **Imports**: Update all existing imports in the entire codebase that currently point to `vpn_node.py` for these protocol-specific items to point to `p2pvpn_common.protocol.packet`.
- **Tests**: Move and update any associated tests to the directory `tests/p2pvpn_common/protocol/`.
- **Circular Dependency Check**: Ensure that `p2pvpn_common` does not import anything from the original `vpn_node.py`.

## Success Criteria
- Protocol logic works perfectly in the new module.
- No `ImportError` or circular dependencies.
- Existing protocol-related tests pass in the new location.

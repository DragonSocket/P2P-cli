# Task 1.1: Extract STUN Client

## Description
Move the STUN client logic from `stun_client.py` to `p2pvpn_common/protocol/stun.py`. This includes `discover`, `discover_async`, `STUNResult`, `_STUNProtocol`, `_parse_response`, constants (DEFAULT_SERVERS, etc.), and all helper functions.

## Requirements
- **Migration**: Move all logic to the new package module.
- **Imports**: Update all existing imports in the entire codebase that currently point to `stun_client.py` to point to `p2pvpn_common.protocol.stun`.
- **Tests**: Move and update any associated tests to reflect the new import paths.

## Success Criteria
- Code successfully runs from the new location.
- No `ImportError` in the project.
- Existing STUN tests pass.

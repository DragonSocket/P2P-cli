# Task 1.4: Extract Constants

## Description
Move all hardcoded protocol and node constants from `vpn_node.py` to a centralized location in `p2pvpn_common/constants.py`.

## Requirements
- **Migration**: Move constants such as `MAGIC`, `TYPE_DATA`, `TYPE_HELLO`, `HEARTBEAT_INTERVAL`, `PEER_TIMEOUT`, `TAP_MTU`, etc., to `p2pvpn_common/constants.py`.
- **Imports**: Update all existing imports throughout the codebase to use the new constants location.
- **Dependency Tree**: Ensure that `p2pvpn_common/constants.py` remains a "leaf" module (it should not import anything from other parts of the project) to prevent circular dependencies.

## Success Criteria
- No magic numbers or hardcoded constants left in `vpn_node.py`.
- All parts of the application use the centralized constants.
- Project builds and runs without circular import errors.

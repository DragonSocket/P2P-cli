# Task 1.3: Extract and Formalize Models

## Description
Migrate and formalize all relevant models into `p2pvpn_common/models/`. This involves moving data structures out of the main logic and into a dedicated, type-safe package.

## Requirements
- **Migration**: 
    - Move `Peer` to `p2pvpn_common/models/peer.py`.
    - Create `p2pvpn_common/models/vpn_config.py` containing `VPNConfig` (dataclass) and `PeerConfig` (dataclass for nested peer info).
    - Identify and migrate any other data structures in `vpn_node.py` that logically belong in `p2pvpn_common/models/`.
- **Dependency Resolution**: Move essentials constants used by models (e.g., `PEER_TIMEOUT`) to `p2pvpn_common/models/` or `p2pvpn_common/constants.py` to prevent circular imports.
- **Refactor Call-sites**: Update all parts of the codebase to use dataclass attribute access (e.g., `config.ip`) instead of dictionary access (e.g., `config['ip']`).
- **Exposure**: Update `p2pvpn_common/models/__init__.py` to export all models for clean access.
- **Integration**: Update all existing imports across the codebase.

## Verification
- **Regressions**: Run `pytest`.
- **Circular Imports**: Perform a thorough check or use a tool to ensure no circular dependencies were introduced.

## Success Criteria
- All models are type-safe and located in `p2pvpn_common/models/`.
- Codebase is updated to use the new access patterns.
- No circular dependencies.
- All tests pass.

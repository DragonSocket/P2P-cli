# Task 3.1: Daemon Service Entry Point

## Description
Create the primary executable entry point for the VPN daemon in `packages/p2pvpn_daemon/p2pvpn_daemon/main.py`. This file acts as the "Assembler" that wires together all components.

## Requirements
- **Configuration**: Use a dedicated `Configurator` to load settings from CLI arguments or a file.
- **Logging**: Set up the global `logging` configuration so all injected components can report.
- **Assembler (DI)**:
    - Resolve/Instantiate `TAPInterface` (platform-specific).
    - Instantiate `UDPTransport`.
    - Instantiate `PeerManager`.
    - Instantiate `VPNEngine`, injecting the above components via its constructor.
- **Lifecycle Management**:
    - Run the `engine.run()` event loop.
    - Register signal handlers (`SIGINT`, `SIGTERM`) to trigger `engine.shutdown()` for a clean exit.
- **Robustness**: Wrap the entire lifecycle in a `try-except` block to ensure that failures (like permission errors for TAP) are reported cleanly to the user rather than dumping a stack trace.

## Success Criteria
- The daemon starts and runs correctly as a standalone process.
- All components are correctly wired via Dependency Injection.
- Pressing `Ctrl+C` results in a graceful shutdown of all sub-components.
- Errors during initialization are caught and reported elegantly.
